# SafeVisit AI - Landing Page Premium

Landing page interactiva para **SafeVisit AI** en modo Dark Luxury.

## 🚀 Cómo publicar esta página GRATIS en GitHub Pages

1. **Crear una cuenta en GitHub:** Si aún no tienes una, regístrate en [github.com](https://github.com).
2. **Crear un nuevo repositorio:**
   - Haz clic en el botón **"+"** arriba a la derecha y selecciona **New repository**.
   - Ponle como nombre `safevisit-ai` y asegúrate de que esté marcado como **Public**.
   - Haz clic en **Create repository**.
3. **Subir los archivos:**
   - Haz clic en **uploading an existing file**.
   - Arrastra los 4 archivos (`index.html`, `styles.css`, `script.js` y `README.md`).
   - Haz clic en **Commit changes**.
4. **Activar GitHub Pages:**
   - Ve a la pestaña **Settings** de tu repositorio.
   - En el menú izquierdo, entra a **Pages**.
   - En *Build and deployment > Branch*, selecciona `main` (o `master`) y la carpeta `/root`.
   - Haz clic en **Save**.
5. **¡Listo!** En 1 o 2 minutos, GitHub te entregará un enlace público en vivo (ejemplo: `https://tu-usuario.github.io/safevisit-ai/`).
